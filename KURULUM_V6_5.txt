FactoryBox One v6.5.0 Kurulum

1. Backend'i durdurun.
2. ZIP içeriğini C:\New DeviceOs Project klasörünün üzerine çıkarın.
3. Dosyaların değiştirilmesini kabul edin.
4. Backend klasörüne geçin:

   cd "C:\New DeviceOs Project\platform\backend"

5. Backend'i başlatın:

   npm.cmd start

6. Admin panelinde Ctrl + F5 yapın.
7. v6.5.0 sürümünü kontrol edin.
8. SmartAI → AI Raporları ekranını açın.
